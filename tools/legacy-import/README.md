# نقل البيانات من النظام القديم

## المرحلة الحالية: دراسة القاعدة القديمة

`Export-LegacySample.ps1` يقرأ قاعدة النظام القديم دون أي تعديل عليها، ويصدّر عينة صغيرة من كل جدول مهم مع ملخصات.
الأسماء والهواتف والعناوين تُخفى افتراضيًا داخل SQL نفسه.

```powershell
powershell -ExecutionPolicy Bypass -File .\Export-LegacySample.ps1
```

الناتج ملف `legacy-sample.zip` على سطح المكتب.

> كل الاستعلامات مجرَّبة على نسخة مطابقة لهيكل القاعدة القديمة (71 جدولًا) على SQL Server.

## الخطوة التالية

بعد دراسة العينة: أداة استيراد داخل النظام الجديد يشغّلها المستخدم على جهازه، تقرأ القاعدة القديمة مباشرة وتنقل البيانات.
