# دليل التثبيت والتشغيل — نظام إدارة الأعمال المتكامل

## ما تحتاجه
| | |
|---|---|
| **جهاز السيرفر** (أو نفس الجهاز) | Windows 10/11 أو Windows Server، مع **SQL Server** (النسخة المجانية Express تكفي) |
| **أجهزة المستخدمين** | Windows 10/11 فقط — البرنامج يحمل بيئة التشغيل معه، لا حاجة لتثبيت .NET |

## الخطوة 1: تثبيت SQL Server (مرة واحدة على السيرفر)
1. نزّل **SQL Server 2022 Express** من موقع Microsoft واختر التثبيت **Basic**.
2. عند الانتهاء يظهر اسم السيرفر، غالبًا: `localhost\SQLEXPRESS` — احفظه.
3. (للشبكة فقط) إن كانت أجهزة أخرى ستتصل بالسيرفر:
   - افتح **SQL Server Configuration Manager** ← SQL Server Network Configuration ← فعّل **TCP/IP** ثم أعد تشغيل خدمة SQL Server.
   - اسمح بالمنفذ **1433** في جدار حماية Windows.

## الخطوة 2: الحصول على البرنامج
- **الأسهل:** من صفحة المستودع على GitHub ← تبويب **Actions** ← آخر تشغيل ناجح ← **Artifacts** ← نزّل `ERP-WaterFactory-win-x64` وفك الضغط في مجلد (مثل `C:\ERP`).
- **أو** على جهاز فيه .NET 9 SDK: شغّل `tools\publish.ps1` من مجلد المشروع، والناتج في `dist\ERP-WaterFactory-win-x64`.

## الخطوة 3: التشغيل الأول (معالج الإعداد)
شغّل `ERP.Desktop.exe`. أول مرة يظهر **معالج الإعداد**:

1. **الاتصال:** اكتب اسم السيرفر (مثل `localhost\SQLEXPRESS`)، اختر **مصادقة Windows**، ثم اضغط **فحص الاتصال**.
2. **تثبيت جديد:** اسم الشركة، اسم قاعدة البيانات (بأحرف إنجليزية)، واسم دخول وكلمة مرور المدير.
   - فعّل **بيانات تجريبية** إن أردت التجربة أولًا (أصناف مياه، عملاء، مندوب، وصفة إنتاج).
3. اضغط **تنفيذ الإعداد والمتابعة**. خلال دقيقة يُنشأ كل شيء، وتظهر شاشة الدخول.

ما ينشئه المعالج تلقائيًا: قاعدة التحكم، قاعدة المشروع بكل الجداول والإجراءات، دليل الحسابات، كل قواعد **العقل المالي**، الأدوار الجاهزة (مدير عام، محاسب، أمين مخزن، موظف مبيعات، مسؤول الموارد البشرية، مسؤول الإنتاج)، مخزن المنتج التام والمواد الأولية والتالف، الشفت الصباحي، وأوزان الحوافز.

## الخطوة 4: الأجهزة الأخرى على الشبكة (التفاصيل في [دليل تجهيز الشبكة](network-setup.md))
على كل جهاز مستخدم: انسخ مجلد البرنامج وشغّل `ERP.Desktop.exe`، ثم في المعالج:
- اسم السيرفر = اسم/عنوان جهاز السيرفر (مثل `SERVER-PC\SQLEXPRESS` أو `192.168.1.10\SQLEXPRESS`)
- اختر **الاتصال بنظام مثبّت مسبقًا** ← تنفيذ.

> **مصادقة Windows على الشبكة** تتطلب أن يكون لمستخدم Windows صلاحية على SQL Server. البديل الأبسط: أنشئ مستخدم SQL (مثل `erp_app`) من SSMS واستخدم **مستخدم SQL Server** في المعالج.

## بعد التثبيت: ما يفعله المدير أولًا
1. **إعدادات النظام ← المستخدمون:** أنشئ حساب دخول لكل موظف واختر دوره (الحساب يعمل فورًا للدخول).
2. **إعدادات النظام ← الأدوار والصلاحيات:** عدّل الصلاحيات الجاهزة حسب الحاجة.
3. **المخازن ← الأصناف وهيكلية التعبئة:** أدخل أصنافك (القطعة تُنشأ تلقائيًا، أضف الشرنك/الكارتون).
4. **المالية ← أسعار الصرف:** سعر الدولار إن وُجد موظفون برواتب بالدولار.
5. **المبيعات ← رسوم التحميل، أسعار الوكلاء، العملاء.**
6. **الموارد البشرية ← الموظفون، إعدادات الحافز الشهري** (المقياس الافتراضي فارغ — أدخل شرائحكم).

## النقل من نظام الرحمة القديم
**إعدادات النظام ← النقل من نظام الرحمة** (للأدمن، مرة واحدة لكل مشروع). يقرأ القاعدة القديمة على نفس السيرفر دون تعديلها، وينقل الأصناف والوصفات والملصقات الخاصة، العملاء وديونهم وتأميناتهم، الموردين وذممهم، الموظفين وسلفهم، أرصدة المخزون، والصناديق بالجرد الفعلي. **«تجربة ومطابقة»** تعرض كل رقم قديم مقابل الجديد دون حفظ، و**«تنفيذ النقل»** يحفظ فقط إن تطابقت كلها. ابدأ بمشروع تجريبي. التفاصيل في `tools/legacy-import/README.md`.

## التحديثات
عند تشغيل نسخة أحدث من البرنامج، **تُرقّى قاعدة البيانات تلقائيًا** عند فتح المشروع (جدول `SchemaVersions` يسجّل ما نُفّذ). لا حاجة لتشغيل أي سكربت يدويًا، ولا تُمس بياناتك.

## النسخ الاحتياطي (مهم)
- **من داخل البرنامج:** إعدادات النظام ← **النسخ الاحتياطي** ← "نسخ احتياطي الآن". تُنسخ قاعدة المشروع وقاعدة التحكم معًا إلى مجلد على **جهاز السيرفر** (الافتراضي مجلد Backup الخاص بـ SQL Server)، ويظهر سجل كل النسخ السابقة.
- لوحة المعلومات تُظهر للمدير بطاقة **"آخر نسخة احتياطية"** باللون الأحمر إن مرّ يوم بلا نسخة.
- انسخ ملفات `.bak` دوريًا إلى قرص خارجي أو جهاز آخر — نسخة على نفس القرص لا تحمي من تلف القرص.
- **الاستعادة:** أغلق البرنامج على كل الأجهزة، ثم من SSMS: زر يمين على Databases ← Restore Database ← Device ← اختر ملف `.bak`.

## واجهة لكل مخزن
وحدة **المخازن** فيها تبويب مستقل لكل مخزن (المنتج التام، المواد الأولية، الكاش فان، التالف، وأي مخزن تضيفه من "تعريف المخازن" يظهر فورًا):
- **عملية جديدة:** إدخال مخزني، إخراج مخزني (لجهة أو غرض)، مناقلة إلى مخزن آخر، تالف (مع السبب والنقل لمخزن التالف)، مسحوب مجاني (باسم المستفيد). كل عملية مستند مرقّم يُطبع.
- **الأرصدة الحالية** لهذا المخزن وحده، بالقطعة وبوحدات التعبئة (مثل "10 كارتون + 3").
- **التقارير:** الرصيد والمتبقي (أول المدة، وارد، صادر، تالف، مجاني، المتبقي)، كشف الحركة التفصيلي برصيد تراكمي، وقائمة المستندات — وكلها قابلة للطباعة.

## الصناديق المالية
**المالية ← الصناديق** (ويظهر للموظف كـ "صندوقي" في المبيعات):
- صندوق رئيسي يُنشأ تلقائيًا، ويمكن للأدمن إنشاء صندوق لكل مستخدم.
- المبيعات النقدية وسندات القبض/الصرف النقدية وتسليم نقد المندوب تدخل الصندوق تلقائيًا (صندوق المستخدم، أو الافتراضي).
- إيداع، سحب، مناقلة بين الصناديق — لا يُسمح برصيد سالب، وكل حركة تُطبع بإيصال فيه المبلغ كتابةً.
- **التعديل والإلغاء للأدمن فقط** (من يملك صلاحية تعديل إعدادات النظام): يُحفظ المبلغ الأصلي ومن عدّل ومتى، والإلغاء يُبقي الحركة مشطوبة في الكشف ويعكس قيدها. حركات الفواتير والسندات لا تُعدَّل من الصندوق.

## لوحة كل قسم
"الرئيسية" في كل وحدة تبدأ بمؤشرات اليوم ورسوم النشاط اليومي لآخر 14 يومًا (مرّر الفأرة فوق أي يوم لتفاصيله) ورسوم ترتيب (أكثر الأصناف مبيعًا، أرصدة الصناديق، المخزون حسب المخزن...).

## البحث في القوائم المنسدلة
كل قائمة منسدلة فيها مربع بحث: اكتب جزءًا من الاسم أو الكود (لا يهم الهمزة أو التاء المربوطة)، ثم Enter لاختيار أول نتيجة أو الأسهم للتنقل، وEsc للإغلاق. يمكنك البدء بالكتابة مباشرة والقائمة مغلقة.

## الطباعة
**هوية الطباعة (مرة واحدة):** إعدادات النظام ← **هوية الطباعة**: الشعار (PNG/JPG)، اسم الشركة عربي/إنجليزي، أرقام الهاتف، العنوان، الرقم الضريبي والسجل التجاري، لون العلامة، ونص التذييل. تظهر تلقائيًا في كل مستند مطبوع. زر "معاينة مستند نموذجي" يريك الشكل قبل الحفظ.

**شكل كل مستند A4:** الترويسة (الشعار والشركة والاتصال على اليمين، عنوان المستند ورقمه على اليسار، خط بلون العلامة) والتذييل (صفحة س من ص، وقت الطباعة، نص التذييل، اسم من طبع) يتكرران في كل صفحة. الألوان فقط في الخط الفاصل ورأس الجدول والإجمالي النهائي.

**نافذة المعاينة قبل الطباعة:**
- **نوع الطابعة:** A4، أو **كاشير حراري 80mm** للفواتير وإيصالات الصندوق والسندات (إيصال ضيق بطول المحتوى، بأعمدة الصنف/الكمية/السعر/المبلغ فقط).
- **الأعمدة الظاهرة:** أزل علامة أي عمود لإخفائه من الطباعة (مثل الملاحظات أو المستخدم عند الطباعة لعميل).
- **إخفاء الصفوف الصفرية أو الفارغة** (مثل الأصناف برصيد صفر).
- **حفظ كإعداد افتراضي لهذا التقرير:** لا تُعيد الضبط كل مرة. آخر نوع طابعة لكل نوع مستند يُتذكّر تلقائيًا.
- **طباعة** أو **حفظ PDF** (يختار "Microsoft Print to PDF" مباشرة). المعاينة هي ناتج الطباعة نفسه.

**ما يُطبع:** الفواتير (ومن قائمة الفواتير)، كشف حساب العميل، أمر الإنتاج، شهادة الفحص المختبري، محضر التعبئة، سندات القبض والصرف، القيود، أوامر الشراء ومحاضر الاستلام، كشف الرواتب، كشف المحفظة وجرد السيارة، مستندات المخازن وتقاريرها، وإيصالات وكشوف الصناديق.

## حل المشكلات
| الرسالة | الحل |
|---|---|
| تعذّر الاتصال بالسيرفر | تأكد من اسم السيرفر (مع `\SQLEXPRESS` إن كانت Express) وأن خدمة SQL Server تعمل |
| قاعدة التحكم غير مثبّتة | اختر "تثبيت جديد" في المعالج |
| اسم المستخدم أو كلمة المرور غير صحيحة | يُنشئ المدير الحساب من إعدادات النظام ← المستخدمون |
| اسم الدخول "admin" موجود مسبقًا في قاعدة التحكم... | تثبيت سابق على نفس السيرفر استخدم نفس اسم الدخول. أدخل كلمة مروره القديمة، أو فعّل **"إعادة تعيين كلمة مرور الحساب الموجود"** في المعالج |
| نسيت كلمة مرور المدير | احذف ملف الإعداد (أدناه) ← شغّل البرنامج ← تثبيت جديد بنفس قاعدة التحكم وقاعدة المشروع واسم الدخول ← كلمة مرور جديدة ← فعّل **إعادة تعيين كلمة مرور الحساب الموجود**. بياناتك لا تُمس |
| قاعدة الربط المحاسبي ... غير معرّفة | المالية ← العقل المالي ← أضف القاعدة (تظهر القواعد الناقصة أعلى الشاشة) |

مكان ملف الإعداد: `%AppData%\ERP-WaterFactory\appsettings.json` — احذفه لإعادة تشغيل معالج الإعداد.
