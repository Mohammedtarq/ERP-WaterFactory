# خطة التكامل: المنصة السحابية والتطبيقات وn8n

> محفوظة بطلب المدير بتاريخ 2026/10/05. **للاطلاع والتخطيط، ولا يبدأ تنفيذها إلا بأمر صريح.**
> ربط n8n كان مؤجَّلًا باتفاق سابق، ويبقى كذلك حتى يُرفع التأجيل.

## المبدأ الحاكم
- **قاعدة المعمل (SQL Server الحالي) هي الأصل**، وفيها الحسابات والقيود. السحابة وسيط فقط.
- **المعمل لا يتوقف إذا انقطع الإنترنت**: النظام المكتبي يعمل محليًا كما هو اليوم.
- **لا يُفتح أي منفذ في المعمل**: خدمة المزامنة في المعمل هي التي تتصل بالسحابة وتعود.
- **لا أحد يكتب في القاعدة مباشرة من الخارج**: كل تغيير يمر بخدمات النظام نفسها (الصلاحيات، قفل الشهر، حد الدين، سجل الحركات).
- **الحساب السحابي باسم المعمل وبطاقته**، والملكية والبيانات للمعمل.

## البنية
```
تطبيق المندوب (أندرويد، يعمل بلا إنترنت)  ┐
لوحة المدير على الهاتف (اطلاع فقط)         ├─⇅─  الخادم السحابي: واجهة برمجية + قاعدة وسيطة (+ n8n لاحقًا)
تطبيق الزبائن (ويب قابل للتثبيت)           ┘          ⇅  خدمة مزامنة على جهاز المعمل (اتصال صادر فقط)
                                                    قاعدة المعمل = الأصل
```

## 1) الخادم السحابي
| البند | التوصية |
|---|---|
| المزوّد | Azure، منطقة الإمارات (دبي). البديل: AWS البحرين |
| المكوّنات | واجهة برمجية ‎.NET تعيد استخدام خدمات النظام الحالية، وقاعدة وسيطة (Azure SQL أو SQL Server Express على خادم واحد) |
| الكلفة التقديرية | بين 30 و80 دولارًا شهريًا لسبعة مندوبين، تُراجَع بحاسبة الأسعار قبل الاشتراك |
| الحماية | اتصال مشفّر، وأجهزة مسجّلة يمكن إيقافها، وصلاحيات حسب الدور، ونسخ احتياطي تلقائي |

**ما يُضاف للنظام المكتبي:** خدمة المزامنة، وشاشة «طلبات المندوبين والزبائن» للموافقات، وإدارة الأجهزة، ومؤشر حالة المزامنة.

## 2) تطبيق المندوبين (م7)
- أندرويد بتقنية ‎.NET MAUI، وقاعدة محلية للعمل بلا إنترنت، ومزامنة عند توفر الشبكة.
- **من المعمل إليه:** العملاء، وأسعار كل وكيل، والأصناف ووحداتها، ورصيد السيارة، وطلبات التحميل المجهّزة، وحد الدين.
- **منه إلى المعمل:** الفواتير، والتحصيلات، والمجاني بالعميل والسبب، والمصاريف بصورة الوصل، وطلب التسوية.
- لكل عملية رقم فريد فلا تتكرر، وتعارضات المزامنة تُسوّى من الشاشة الموجودة أصلًا.
- الطباعة: بلوتوث، أو طابعة جهاز الكاشير الداخلية عبر حزمة الشركة المصنّعة.

## 3) لوحة المدير على الهاتف (اطلاع فقط)
- مبيعات اليوم والشهر، والصناديق، والمخزون وتنبيهاته، والمندوبون وتسوياتهم، وديون العملاء، والحسابات الختامية.
- تخضع للصلاحيات: الأرباح والكلفة للمدير فقط.
- **قبلها ومتاح الآن:** التحكم عن بُعد بحاسوب المعمل (AnyDesk أو Chrome Remote Desktop) بكلمة مرور قوية.

## 4) كشوف الحساب للعملاء والموردين
| المستوى | الطريقة | يحتاج |
|---|---|---|
| متاح الآن | الكشف ← طباعة ← «حفظ PDF» ← إرسال على WhatsApp | لا شيء |
| ✅ منفَّذ | زر «WhatsApp» في كشف العميل وكشف المورد: يفتح المحادثة برقم البطاقة ونص الرصيد وآخر 5 حركات | لا اشتراك |
| آلي | كشف أول كل شهر وتذكير للمتأخرين | n8n مع WhatsApp Business أو Telegram |
| رابط شخصي | رابط آمن دائم لكل عميل يفتح كشفه ورصيده محدّثًا | الخادم السحابي |

شرط مشترك: رقم هاتف صحيح في بطاقة كل عميل ومورد.

## 5) تطبيق الزبائن
- **التثبيت:** تطبيق ويب قابل للتثبيت (PWA) على أندرويد والآيفون بلا متجر، ثم المتاجر إذا كبر العدد.
- **الزبون:** يدخل برقم هاتفه ورمز تحقق، ويرى المنتجات بسعره الخاص وبالكارتون أو الشرنك، ويطلب ويتابع الحالة، ويرى رصيده وكشفه.
- **المعمل:** الطلب يصل إلى «طلبات الزبائن»، ويُطبَّق حد الدين تلقائيًا، ثم يتحول إلى فاتورة أو يُضاف إلى حمولة مندوب المنطقة.
- **قرارات مطلوبة قبل التنفيذ:** من يوصل (المندوب أم سيارة المعمل)، والحد الأدنى للطلب وموعد الاستلام اليومي، وطريقة الدفع لكل عميل.

## 6) n8n (مؤجَّل)
**طرق الربط بالترتيب حسب الأمان:**
1. قراءة «تقارير جاهزة» بمستخدم قاعدة للقراءة فقط (لا جداول خام ولا كلمات مرور).
2. أحداث يرسلها النظام من جدول أحداث، ولا يضيع شيء عند انقطاع الإنترنت.
3. واجهة برمجية بمفتاح خاص ودور «n8n» في الصلاحيات، لإجراءات محدودة مثل الموافقات، وكلها في سجل الحركات.
4. وكيل ذكي يجيب عن أسئلة حرة بأدوات قراءة فقط.

**أمثلة مسارات من خطة العمل:**

| البند | المسار |
|---|---|
| تقرير المدير اليومي | 9 مساءً: المبيعات والتحصيلات والصندوق، رسالة مع PDF |
| متابعة المندوبين | كل صباح: من تأخرت تسويته أكثر من يوم |
| حد الدين | لحظة الرفض: رسالة للمدير بزرّي موافقة/رفض |
| المخزون | المواد عند نقطة إعادة الطلب ← قائمة شراء |
| المصروفات | كل مصروف فوق مبلغ محدد ← إشعار فوري |
| نهاية الشهر | يوم 25 تذكير بإغلاق المسحوبات، وأول الشهر ملخص الختامية |

**لبدء n8n:** رفع التأجيل، وخطة العمل (ماذا يصل ومتى ولمن وأي موافقات من الهاتف)، واختيار القناة (Telegram أو WhatsApp Business).

## الترتيب المقترح للتنفيذ
1. الخادم السحابي وخدمة المزامنة.
2. تطبيق المندوبين.
3. لوحة المدير على الهاتف.
4. تطبيق الزبائن ورابط كشف الحساب.
5. n8n عند رفع التأجيل.

زر «إرسال الكشف على WhatsApp» منفَّذ (2026/10/06).

## المطلوب من المعمل
1. الموافقة على المزوّد والمنطقة.
2. فتح حساب الاستضافة باسم المعمل وبطاقته.
3. اسم نطاق (مثل api.alrahma-water.com).
4. طراز جهاز الكاشير بالطابعة الداخلية وطراز طابعة البلوتوث.
5. قرارات تطبيق الزبائن (التوصيل، الحد الأدنى، موعد الاستلام، الدفع).
