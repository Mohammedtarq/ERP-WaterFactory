# قرارات التصميم والتقارير (من النقاش مع المالك)

- **بداية الأسبوع:** السبت (ينتهي الجمعة) في كل التقارير والتحليلات.
- **تقرير الكلفة والربح:** للمدير فقط (صلاحية خاصة، ويظهر بقفل لغيره).
- **قاعدة الكمية:** كل كمية تُعرض «المنتج + العبوة + العدد»، ولا يُجمع كارتون منتج مع كارتون منتج آخر. تسري على كل التقارير والشاشات والطباعة وتطبيق المندوبين.
- **التقارير المطلوبة:** المبيعات والمرتجع والمجاني بالنوع والعدد، والإنتاج يومي وأسبوعي وشهري.
- **التنقل:** قائمة يمنى بالأقسام، ولوحة بلاطات تنفتح من القسم (شكل النظام القديم) بتقسيمات القسم، وفي آخر كل مجموعة بلاطتا «تحليل» و«تقارير» ثم قائمة اختيار ثم عرض موحد.
- **المظهر:** خمسة ألوان يختار منها كل مستخدم (أزرق، سماوي، فيروزي، نيلي، زمردي) مع أيقونات حديثة ثنائية اللون (Phosphor Icons، رخصة MIT).
- **تطبيق المندوبين:** يبقى بالأزرق.
- **صور الخطة:** `docs/plan/` (الصور 01–15)، `final/`، `legacy-look/`، `modern/`.
- **حالة التنفيذ:** لم يبدأ. بانتظار اعتماد التصميم ثم المرحلة 1.
