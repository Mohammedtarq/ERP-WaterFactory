# فحص النظام الشامل — ملاحظات كل قسم والمقترحات

> **طريقة الفحص:** صور الشاشات الفعلية من خادم Windows (`docs/ci-screens`) ببيانات يوم تجربة بشكل بيانات المعمل
> (سدادات بألوان، ليبل بأسماء زبائن، أسماء خاصة، تالف مختلط، مستندات متعددة الأسطر — `ERP.Data/Setup/TrialDayData.cs`)،
> مع قراءة الكود وتشغيل كل الاختبارات (306 اختبارًا على SQL Server حقيقي).
>
> **الرموز:** ✅ أُصلح ومُختبَر · 🟡 مقترح بانتظار موافقتك · ❓ سؤال يحتاج قرارك

## 0) أدوات الفحص (حتى لا يتكرر ما فاتني)
- ✅ صور الشاشات الفعلية تُحفظ في المستودع (`docs/ci-screens`) عند كل دفعة فيها `[shots]`؛ صرت أرى كل شاشة وكل تبويب داخلي.
- ✅ كانت صور الأقسام كلها مغطاة بقائمة الوحدة المنبثقة (لا يُرى المحتوى) — أُصلح الاختبار.
- ✅ شاشة خادم الفحص كانت 1024 بكسل فتُقصّ الشاشات؛ رُفعت إلى 1920×1080 ونافذة 1600×900.
- ✅ «يوم تجربة» يملأ الشاشات ببيانات بشكل بياناتك (لا أرقامك الحقيقية).
- ✅ اختبارات جديدة تفحص ظهور **اسم الصنف** في كل نوع مخزن، وأن الإجماليات لا تجمع وحدات مختلفة.
