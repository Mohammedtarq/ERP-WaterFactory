# أمر يومي واحد بكل الأصناف

> صور هذا الدليل في `images/variants/` تُلتقط من الشاشات الفعلية (اختبار `Illustrated_guide_production_variants`).

## الفكرة في سطر
المنتج واحد (ماء الرحمة)، ويُعبّأ **شرنك أو كارتون** (وحدتا تعبئة للصنف نفسه).
**المتغير** = وصفة تستبدل الغطاء أو الليبل فقط: مطعم (محجوز له) أو مناسبة (تُباع لمن يطلبها).
كل سطر في أمر اليوم يُنتج **تشغيلة تحمل اسم متغيرها**، والمخزون والبيع والتحميل يحترمونها.

| المتغير | من يأخذ منه تلقائيًا |
|---|---|
| أساسي | كل زبون، وكل حمولة عامة |
| مطعم (محجوز) | المطعم نفسه أولًا، ثم الأساسي. لغيره فقط بصلاحية «البيع من رصيد محجوز لعميل آخر» |
| مناسبة | من يختارها بالاسم في الفاتورة («تلقائي — زواج سعيد») |

## الخطوات
1. **متغير جديد** (الإنتاج ← الوصفات المخصصة ← «متغير جديد بخطوة واحدة»): المنتج ← المطعم أو «مناسبة عامة» ← ما يتغير (الغطاء/الليبل): صنف موجود أو «صنف جديد باسم». الصنف الجديد مادة أولية تُشترى وتُستلم كالعادة.
2. **أمر اليوم** (الإنتاج ← إنتاج اليوم): سطر لكل (منتج × متغير × وحدة). المنتج نفسه يتكرر بلا حدود.
   - «تكرار آخر إنتاج» يملأ سطور آخر يوم، و«القالب» يحفظ أمرًا مسمّى (أمر الأحد...).
   - «فحص المواد» يعرض احتياج كل مادة (ومنها ليبل كل مطعم) مقابل المتاح قبل التسجيل.
3. **البيع**: حقل «التشغيلة / المتغير» — تلقائي = الأساسي ومحجوز هذا الزبون؛ أو اختر متغيرًا بالاسم. «المتاح» يُحسب لهذا الزبون.
4. **طلب التحميل**: عمود «المتغير» — الأساسي حمولة عامة؛ اسم المطعم لتحميل تشغيلاته وتوصيلها له.
5. **متغيرات المنتج** (الإنتاج): لكل متغير المنتج والمبيع والرصيد الآن وكلفة القطعة، والتشغيلات بأرصدتها، وتصحيح متغير تشغيلة سُجّلت خطأً (بالصلاحية، مع السبب في سجل الحركات).
6. **أرصدة المخزن**: عمود «المتغير» بجانب التشغيلة.

## أسئلة سريعة
- **نفد الأساسي وعندي رصيد مطعم؟** الفاتورة ترفض وتذكر الرصيد المحجوز. المدير (أو من يملك الصلاحية) يبيع منه، والأساسي يُصرف أولًا دائمًا.
- **البيع بانتظار الإنتاج** يخص الأساسي فقط، ولا يُسوّى من تشغيلة مطعم.
- **حمولة المندوب الافتراضية** أساسية؛ أضف سطر المطعم يدويًا في طلب اليوم.
