# نشر الخادم السحابي: AWS Lightsail (مومباي) + النطاق babalrahma.com

> دليل خطوة بخطوة للمرحلة 1-ب من `docs/integration-plan.md`. الخادم السحابي = صندوق بريد صغير؛ الأصل في قاعدة المعمل.
> أسماء الأزرار في مواقع AWS وCloudflare قد تتغير قليلًا؛ المعنى واحد.

## القرارات
| البند | القرار |
|---|---|
| الاستضافة | AWS Lightsail، منطقة **مومباي (ap-south-1)** — Lightsail غير متوفر في البحرين |
| الخطة | Linux/Unix ← **Ubuntu 24.04 LTS** (نظام فقط) ← خطة **7$** (1GB ذاكرة، 2 معالج، 40GB SSD) |
| النطاق | `babalrahma.com` يُشترى من Cloudflare |
| العنوان للهواتف | `https://rep.babalrahma.com` |
| التكلفة التقريبية | نحو 7$ شهريًا + نحو 10–12$ سنويًا للنطاق (تحقق من الأسعار الحالية عند الشراء) |

## 1) شراء النطاق (Cloudflare)
1. https://dash.cloudflare.com/sign-up ← أنشئ حسابًا ببريد المعمل وفعّل البريد.
2. من القائمة: **Domain Registration ← Register Domains** ← ابحث عن `babalrahma.com` ← اشترِه (بطاقة دفع دولية).
3. النطاق يظهر في **Websites**؛ ادخله ← **DNS ← Records** (نضيف السجل في الخطوة 4).

## 2) حساب AWS وإنشاء الخادم
1. https://portal.aws.amazon.com/billing/signup ← حساب باسم المعمل، بطاقة دولية، تحقق بالهاتف، خطة الدعم **Basic** (مجانية).
2. ادخل https://lightsail.aws.amazon.com ← **Create instance**:
   - الموقع: **Asia Pacific (Mumbai)**، المنطقة A.
   - المنصة: **Linux/Unix** ← **OS Only** ← **Ubuntu 24.04 LTS**.
   - الخطة: **7$** (1GB).
   - الاسم: `erp-relay` ← **Create instance**.
3. **Networking ← Create static IP** (مومباي) ← اربطه بالخادم `erp-relay`.
   بدونه يتغير عنوان الخادم عند إيقافه. دوّن العنوان (مثل `13.xxx.xxx.xxx`).
4. على الخادم ← **Networking ← IPv4 Firewall ← Add rule**: أضف **HTTP (80)** و**HTTPS (443)**.
   (SSH 22 موجود افتراضيًا؛ يمكن تقييده بعنوان معمل لاحقًا.)

## 3) ربط النطاق
في Cloudflare ← النطاق ← **DNS ← Add record**:
- Type: **A**، Name: **rep**، IPv4: **عنوان Static IP**.
- **Proxy status: DNS only** (السحابة رمادية، لا برتقالية) حتى يستخرج Caddy الشهادة بلا تعارض.

## 4) تثبيت Docker على الخادم
Lightsail ← الخادم ← **Connect using SSH** (نافذة المتصفح) ثم:
```
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker ubuntu
```
أغلق النافذة وافتحها من جديد. اختبر: `docker --version`.

## 5) ملفات النشر من البرنامج (على حاسبة المعمل)
1. **الإعدادات ← المزامنة السحابية**: اكتب في «عنوان الخادم السحابي» `https://rep.babalrahma.com` ← **حفظ**.
2. اضغط **ملفات نشر الخادم السحابي**: يُنشأ مجلد في «المستندات» فيه `docker-compose.yml` و`Caddyfile` و`.env` (بمفتاح المعمل) ومجلد `app`.
   > ملف `.env` فيه مفتاح المعمل: لا تشاركه ولا ترسله بالبريد.

## 6) رفع المجلد وتشغيله
1. حمّل **WinSCP** (https://winscp.net). مفتاح الدخول: Lightsail ← **Account ← SSH keys** ← حمّل المفتاح الافتراضي لمنطقة مومباي (ملف `.pem`). في WinSCP: بروتوكول SFTP، المضيف = Static IP، المستخدم `ubuntu`، ثم **Advanced ← SSH ← Authentication** واختر ملف المفتاح (يطلب تحويله إلى `.ppk`، وافق).
2. ارفع المجلد كاملًا إلى `/home/ubuntu/erp-relay`.
3. في نافذة SSH:
   ```
   cd ~/erp-relay
   docker compose up -d
   ```
4. افتح في المتصفح `https://rep.babalrahma.com/api/health` — يجب أن يظهر `"ok":true` (الشهادة تستغرق دقيقة في أول مرة).

## 7) ربط النظام والهواتف
1. في البرنامج: **الإعدادات ← المزامنة السحابية ← اختبار الاتصال** ثم **حفظ** مع التفعيل.
2. خدمة المزامنة على الحاسبة (نسخة اليوم) ترفع الحركات ونسخة العمل للخادم السحابي وحدها.
3. الهواتف تأخذ العنوان السحابي مع نسخة العمل التالية، **دون إعادة ربط**. جرّب هاتفًا على بيانات الشريحة (أطفئ الواي فاي).

## الأمان والصيانة
- **لا تشارك:** ملف `.env` ولا مفتاح `.pem`.
- **النسخ الاحتياطي:** لا حاجة لنسخة للخادم؛ الأصل في قاعدة المعمل. يمكن تفعيل لقطات Lightsail (Snapshots) اختياريًا (تُحتسب رسومها).
- **تحديث الخادم:** انسخ مجلد `app` الجديد من ملفات النشر ثم `docker compose restart relay`.
- **انقطاع الإنترنت عن المعمل:** تنتظر الحركات على الخادم السحابي وتصل المعمل عند عودة الاتصال.
- **الإيقاف لا يوفّر المال:** الخادم المتوقف يُحاسَب بنفس سعر الخطة؛ للإلغاء احذفه.
- **قفل SSH (اختياري):** من جدار حماية الخادم قيّد المنفذ 22 بعنوان إنترنت المعمل إن كان ثابتًا.

## 8) لوحة المدير على الهاتف (قراءة فقط)
صفحة ويب تُثبَّت كتطبيق على الهاتف: `https://rep.babalrahma.com/manager/`

**ما تعرضه:** مبيعات اليوم والمحصَّل والآجل والمصروفات، أرصدة الصناديق، رسم مبيعات 30 يومًا، التنبيهات، المندوبون (المبيعات والنقد وآخر اتصال)،
المنتجات تحت حد التنبيه وأرصدة المنتجات التامة، أكبر الديون، الحضور والإجازات والعلاوات القادمة. **لا رواتب ولا سلف ولا أي تعديل أو حذف.**

**التشغيل (مرة واحدة):**
1. حدّث الخادم السحابي بنسخة البرنامج الجديدة (الخطوة التالية)، فاللوحة جزء منه.
2. في البرنامج: **الإعدادات ← المزامنة السحابية ← لوحة المدير على الهاتف**: اكتب اسم مستخدم (3 أحرف فأكثر) وكلمة مرور (8 فأكثر) ← **حفظ حساب المدير**. يصل الخادم خلال دقيقة.
3. على الهاتف افتح الرابط، سجّل الدخول، ثم من قائمة المتصفح **إضافة إلى الشاشة الرئيسية**.

**الأمان:** كلمة المرور لا تُخزَّن نصًّا (تُجزَّأ في المعمل)، والخادم لا يراها؛ بعد 5 محاولات خاطئة يُقفل الدخول 15 دقيقة؛ إيقاف الحساب أو حذفه من البرنامج ينهي جلسته على الهاتف خلال دقيقة؛
الأرقام تُحدَّث كل دقيقة من حاسبة المعمل، وإن كانت مطفأة تظهر عبارة «آخر تحديث قبل …».

### تحديث الخادم بالنسخة الجديدة (يلزم مرة لهذه الميزة، ثم عند أي تحديث للخادم)
1. من حاسبة المعمل (بعد تثبيت النسخة الجديدة): **ملفات نشر الخادم السحابي** يُنشئ مجلدًا جديدًا.
2. ارفع منه مجلد **`app`** فقط إلى `/home/ubuntu/erp-relay` واستبدله (WinSCP). لا ترفع `.env` إلا إن تغيّر مفتاح المعمل.
3. في SSH:
   ```
   cd ~/erp-relay && docker compose restart relay
   ```
4. افتح `https://rep.babalrahma.com/manager/` — تظهر شاشة الدخول.

## 9) شاشة التلفاز في المعمل
صفحة تُفتح في متصفح أي تلفاز ذكي أو جهاز صغير موصول بشاشة: `https://rep.babalrahma.com/tv/`

**ما تعرضه (شرائح تتبدل كل 10 ثوانٍ):** مبيعات اليوم و10 أيام، أوامر الإنتاج والمنتج المصنَّع وفحص الجودة، المندوبون المتصلون، المنتجات تحت حد التنبيه، حضور الأقسام (أعداد بلا أسماء)، ورسالة ثابتة من المدير إن وُجدت.
**لا تعرض:** ديونًا ولا أرصدة صناديق ولا رواتب ولا سلفًا.

**التشغيل:**
1. حدّث الخادم كما في القسم 8 (مجلد `app` ثم `docker compose restart relay`).
2. **الإعدادات ← المزامنة السحابية ← لوحة المدير على الهاتف**: اكتب اسمًا وكلمة مرور، **علّم «هذا حساب شاشة التلفاز»** ← حفظ. حساب التلفاز لا يفتح لوحة المدير.
3. على التلفاز افتح الرابط وسجّل الدخول؛ للشاشة الكاملة اضغط F أو انقر مرتين. لتغيير مدة الشريحة: `/tv/?s=15`.
4. الرسالة الثابتة: من القسم نفسه «شاشة التلفاز في المعمل» ← حفظ الرسالة (تظهر خلال دقيقة).
